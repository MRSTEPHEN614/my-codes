# Python Expense Tracker

A simple, menu-driven expense tracking application built with Python. This project helps users record expenses, view their spending, calculate total expenses, and see how much they spend in different categories.

## Features

- **Add Expenses:** Record an expense with an item name, amount, and category.
- **View Expenses:** Display all expenses recorded during the current session.
- **Calculate Total:** Calculate the total amount spent.
- **Category Breakdown:** Group expenses by category and calculate spending for each category.
- **Input Validation:** Handle invalid numerical input to prevent the program from crashing.

## Technologies Used

- Python 3
- Python functions, lists, and dictionaries
- Loops and conditional statements
- Exception handling

## Getting Started

### Prerequisites

Install Python 3 on your computer.

### Installation

1. Clone or download this repository.
2. Open the `expense-tracker` folder.
3. Run the Python file from your terminal.

```bash
python expense_tracker.py
```

If your Python installation uses the `python3` command, run:

```bash
python3 expense_tracker.py
```

Replace `expense_tracker.py` with your actual Python filename if it differs.

## How to Use

1. Run the program.
2. Choose an option from the menu.
3. Add expenses by entering the item name, amount, and category.
4. View your recorded expenses, total spending, or category breakdown.
5. Select the exit option to close the program.

## Current Limitations

- Expenses are stored in memory and are lost when the program exits.
- The application currently runs in the terminal.
- It does not yet include a graphical interface or database.
